# 整理后验收

所有模式执行 a–e；重构执行 f，论文知识提取执行 g，自绘图执行 h。每项标记「通过 / 未通过 / 不适用」并保留必要证据；未验证不是通过。任何适用的必需项未通过，都不能宣布整体完成验收；简短说明缺口与下一步，不用其他项的完成抵消。

## a. 用户指令与范围

- 逐条对账：用户要求了什么、实际完成什么、落在哪份笔记 / 产物。
- 点名笔记必须写入该位置；未点名时放在授权主题内合理位置。不扩写无关主题，不改无关文件；图片、绘图源码和来源记录作为配套产物一并列入。
- 源材料缺失、不含指定内容、或授权歧义时说明哪项未完成及原因，不以邻近主题顶替。
- 重大重构、知识性纠错、入链修复遵循 `SKILL.md` 的授权边界；已有明确授权不重复索取。

## b. 科研风格与正确性（所有模式必查）

以 `style.md` 为定义，逐项核对正文、公式、表格、图注和自绘图：

| 检查项 | 通过条件 |
| --- | --- |
| 论述身份 | 来源事实、作者主张、推导、经验结果有区分；假设与适用条件没有丢失，未核实内容如实标注 |
| 标量 / 向量 / 矩阵 | 默认按斜体标量、小写粗斜体向量、大写粗斜体矩阵书写；论文沿用原文时解释约定，代码名保持代码字体 |
| 常量与固定参数 | 数字、单位、算子和描述性标签排版正确；固定参数说明取值或固定范围，不误认为所有固定量都必须正体 |
| 不变量 | 若出现「保持不变」等主张，说明保持什么、在哪些步骤 / 条件下成立，并有来源或推导；无该概念则不适用 |
| 首次定义 | 每个新增符号在首次出现处解释；必要的类型、定义域、维度 / 形状、单位与索引范围完整 |
| 一致性与维度 | 同一作用域符号含义稳定；矩阵乘法、求和、广播与量纲相容；图文记号相符，跨来源差异有映射 |
| 实验 / 数值 | 指标方向、基线、关键配置、单位和相对 / 绝对变化明确；无编造数字或无条件性能保证 |
| 科研图表 | 图表与论述有关，箭头语义可辨、必要图例和来源完整；正文 / 图注足以解释关键符号 |

**实际检查方式**：逐一核对本轮新增或修改的公式及其首次定义，检查关键结论对应的来源；不以搜索到变量名或表格标题就判通过。没有公式的笔记可将相应符号项标为不适用，不为验收凭空造公式。

发现知识性问题按 `SKILL.md` 的 c/d 处理。授权范围内无法核实或暂不能修正的错误要显式报告，不能为了通过而隐去疑点。

## c. 完整性、结构与阅读成本

- 理解用户要求的知识所必需的条件、独有信息和上下文差异均保留，冗余复述已删除。以信息判断，不以行数长短直接判好坏。
- 小幅补充就近融入；长笔记有清楚纲领和合理层次，不为小条目强制补「0 / 1」模板。
- 同级章节同层级；保留原 frontmatter 和必要表格列；相关双链有意义。
- 新增密度与相邻内容协调；没有默认追加零碎误解清单或无关实战案例。
- 需要图示时按 `diagram.md`；简单线性关系或对照表不强制转图。目录重构不以压缩篇幅删减独有知识。

## d. Markdown、公式与链接

- 表格内公式不用裸竖线作绝对值 / 范数 / 条件分隔；用 `\lvert \rvert`、`\lVert \rVert`、`\mid` 等。表格内带别名的 wikilink 也须按 Obsidian 语法处理竖线。
- 公式定界符、括号、环境及代码围栏成对；符号字体在最终渲染中正确，不能只看源码。多栏 PDF 公式不得依靠错序的抽取文本拼造。
- 双链目标、标题锚点、图片路径和必要外链有效；不把未访问的外链声称已联网验证。
- 范围内的纯格式问题可直接修复；范围外问题报告，不借格式检查擅自改全库。

## e. 产物与验收证据

- 本轮图片位于笔记同级 `images/`，命名可辨识且不覆盖同名不同图；引用实际指向这些文件。
- 打开最终笔记 / 图片核看显示，不能仅用文件存在或命令返回零替代视觉检查。无法在 Obsidian 中验证时注明实际检查范围，如「已核看 PNG，Obsidian 嵌入待验证」。
- 新增或修改可复用脚本时执行真实样本测试；依赖安装后核对解释器路径、版本与 `python -m pip check`。
- 报告实际证据和限制；没有执行的检查标待验证。源文件没有被意外覆盖，临时全文 / 页面预览不混入最终知识笔记。

## f. 笔记重构专项

- **知识守恒**：独有事实、公式、代码、条件、来源和原图全部保留。允许合并完全重复表达，保留所有差异。纯移动可对比哈希；合并 / 拆分须逐条内容映射，`git diff --stat` 只能反映规模，不能证明知识守恒。
- **结构与归属**：消除本次范围内的重复、错位和含糊层级；每份笔记忠于其主题。
- **科研表达**：重组后的定义仍在使用前或邻近处，符号作用域未因合并混淆，图注、实验条件和来源随内容走。不能为满足风格擅自补造缺失知识。
- **双链与索引**：核查受迁移 / 重命名 / 标题调整影响的短链、带路径链接、锚点、块引用和 `Sub-item`。全库扫描用于找入链，只修改本次必要受影响引用；不声称修复了所有历史断链。
- **图片与可恢复性**：图片及来源记录、绘图源码一并处理；共享资产仍可被其他笔记解析，无碰撞覆盖。删除仅限已确认内容迁出且引用处理完成的空壳。
- 本轮重构范围中的论文原图不可丢失；纯重构不强制补取原先没有的论文图，若同时做论文知识提取则执行 g。

## g. 论文知识提取专项（原图硬门槛）

1. **至少一张论文原图**：每份论文知识提取笔记实际嵌入至少一张该论文 PDF 的原图；多论文笔记逐篇检查。可以复用既有合格原图。
2. **来源与内容可核验**：图号、1-based PDF 页码和论文来源明确；导出图与原页一致，保留理解所需的坐标轴、单位、图例和子图。默认脚本的同名 JSON 来源记录与文件对应。
3. **已核看图片与嵌入**：图片清晰、不裁掉关键内容、引用有效，正文或图注说明图的作用。图号存在但文件缺失、裁到空白、只有正文截图，都不通过。
4. **不接受替代品**：自绘图、AI 生成图、OCR 转写、表格截图和仅有外链均不能替代原图。
5. **唯一例外为论文全文无图**：须核验正文与附录，记录版本、页数及检查依据；不能依据 `get_images() == []`、关键词未命中或提取失败推断无图。没有拿到全文时该项未通过。
6. **原文忠实性**：核心洞见、公式和关键数值可追溯；定义与关键条件完整，引用符号沿用论文并有必要说明。

## h. 自绘图专项

- 科研表达通过 b；图中符号与正文 / 图注一致，文字、公式和连接关系清晰。
- 输出 `.drawio` 与可编辑的 `.drawio.svg`，两者来自同一内容；SVG 和内嵌 mxfile 可解析，嵌入的模型与源文件语义一致。
- 用可用的 drawio 校验工具检查结构并记录实际输出；若工具不可用说明替代检查，不虚报运行。解决错误，对告警逐项判断。
- 核看渲染：无截字、重叠、错误连线、缺字及未渲染 LaTeX；正常嵌入尺寸可读。自动评分是辅助证据，不能代替视觉检查。
- 独立绘图也适用以上要求；只有源文件或 XML 能解析不能宣称已经完成显示 / 编辑验证。

## 反馈方式

简短列出用户要求的完成位置及适用验收结论；必要时附原图路径、图号 / 页码、所用解释器或脚本测试结果。只汇报真正做过的检查，失败、例外和待验证项必须显式列出。例如：

```text
指令：3 项均落在指定笔记及其 images/。
科研表达：新增符号已定义，形状相容；实验结论保留了基线与配置。
论文原图：已保留 Fig. 2（PDF 第 4 页），核看 PNG 与来源记录。
待验证：当前无法打开 Obsidian，尚未验证应用内嵌入显示。
```
