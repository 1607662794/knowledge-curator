# 口味沉淀

仅沉淀用户明确表达、可跨任务复用的偏好；一次性任务要求不自动升级为永久规则。

## 位置

先确认当前 agent 的记忆机制与可写位置。用户此前使用的 Claude 记忆目录是：

`C:\Users\Administrator\.claude\projects\c--Users-Administrator-OneDrive-------\memory\`

这是历史路径示例，不保证当前存在或适用于其他 agent；没有可用机制时在收尾中说明待沉淀内容，不静默创建无关配置或擅自写入不可用位置。

## 写入规则

- 先读索引和相关记忆，已有同类偏好就更新，不重复累积。
- 用户本轮明确修改了旧偏好时，以新指令为准；只有无法判断是否替代旧规则时才询问。
- 保留简短要求、原因与适用范围；本 skill 的科研规范以 `style.md` 为准，记忆不重复维护另一套冲突定义。
- 用户要求保存具体案例时可按授权记录案例，不强行把案例转成全局偏好。
- 有索引时同步更新，写完只简短说明。

可采用如下反馈格式，或沿用当前 agent 的原生格式：

```markdown
---
name: <简短名称>
description: <适用场景的一行摘要>
type: feedback
---
<要求与适用范围>

**Why:** <反馈的原因>
**How to apply:** <可执行的做法>
```
