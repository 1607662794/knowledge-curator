# 统一科研风格

适用于知识提取 A–D、笔记重构 E、独立绘图 F，以及正文、公式、表格、图注和自绘图。本文件定义风格，`testing.md` 定义如何验收。科研风格以**概念可定义、推理有条件、证据可追溯、符号一致、图表可读**为准，不以术语密度、公式数量或篇幅衡量。

## 1. 论述与证据

- 开头优先给能定位主题的结论或摘要。方法、条件、结果之间关系清楚；小幅融入保留既有结构，不强加整篇模板。
- 区分定义、前提、推导、经验观察和作者结论。推导说明必要假设；实验结果交代比较对象、指标方向和关键配置，避免将相关性当因果、单次观察当普遍规律。
- 引用原文结论时保留来源；补充解释标明其身份。无法核实的部分明确注明「待核实」及缺少的依据，不能为了口吻确定而制造结论。
- 只保留理解和复用需要的条件、步骤、公式及数据。完整性针对用户要求的知识范围，不要求复述原文全部内容。

## 2. 数学记号：按语义排版

下表是自行组织内容时的默认约定。论文沿用原文符号体系，在首次出现处解释；代码标识符用代码字体，并与数学变量建立必要映射。保留论文原图的原始排版，不为统一字体而篡改原图。

| 对象 | 默认写法 | 说明 |
| --- | --- | --- |
| 标量变量、索引 | $x, \alpha, i$ | 数学斜体；标量通常小写，但维度 $N$、随机变量 $X$ 等可按明确约定大写 |
| 向量 | $\boldsymbol{x}$ | 小写粗斜体；注明维度及必要的行 / 列方向 |
| 矩阵 | $\boldsymbol{W}$ | 大写粗斜体；如 $\boldsymbol{W}\in\mathbb{R}^{m\times n}$ |
| 张量、集合 | $\mathcal{X}, \mathcal{S}$ | 说明对象类型、阶数 / 形状或集合含义，避免只靠字体区分歧义 |
| 固定参数 | $\lambda, \eta, N$ | 参数在当前实验中固定仍按数学符号排版；说明固定范围、取值和单位，不一律改成正体 |
| 数字、数学常量 | $2,\ \mathrm{e},\ \mathrm{i},\ \pi$ | 数字正体；自然底数与虚数单位可用正体避免与变量混淆；$\pi$ 沿用通行数学字体 |
| 函数、算子、微分 | $\log,\ \exp,\ \operatorname{diag},\ \mathrm{d}x$ | 名称用正体；变量函数 $f(x)$ 中的 $f$ 仍按数学符号 |
| 转置、逆、索引下标 | $\boldsymbol{W}^{\mathsf{T}},\ \boldsymbol{W}^{-1},\ x_i$ | 转置标签正体；索引 $i$ 斜体；不得混淆转置和求逆 |
| 描述性下标 / 上标 | $d_{\mathrm{in}},\ x_{\mathrm{ref}}$ | `in`、`ref` 是文字标签，用正体；变量索引与文字标签分别排版 |
| 单位、缩写 | $t=2\,\mathrm{s}$、FP16 | 单位和技术缩写用正体；量与单位间留适当间距，不将多字母缩写当作变量连乘 |

**常量与不变量不同**：固定超参数是当前设置不变；算法不变量是某性质在指定步骤或变换中保持成立。提到不变量时写清「什么量 / 性质，在什么步骤或条件下不变」，必要时给依据；不能只凭一个变量名称其为不变量，也不要求每篇笔记都硬造不变量章节。

## 3. 首次定义、形状与一致性

- 每个新符号在首次使用前或同一句 / 紧邻公式之后定义，含含义、对象类型、定义域，及理解所必需的形状、单位、索引范围。长推导可用局部符号表；不要求所有笔记都放总符号表。
- 示例：设 $\boldsymbol{x}\in\mathbb{R}^{n}$ 为列输入向量，$\boldsymbol{W}\in\mathbb{R}^{m\times n}$ 为权重矩阵，$\boldsymbol{y}=\boldsymbol{W}\boldsymbol{x}\in\mathbb{R}^{m}$ 为输出；$n,m$ 分别为输入、输出维度。矩阵乘法、广播和求和须形状相容。
- 同一作用域一符一义、一义尽量一符；跨论文沿用不同原文记号时说明映射，不强行全库替换。方法间确需复用符号时明确局部作用域。
- 数据、单位、百分比与公式的量纲对应；复杂度注明自变量，速度提升说明基线与计量对象。没有原始证据时不补造维度、数值或理论保证。
- 对现有笔记重构，允许无歧义的等价排版和符号规范化；更改定义、补假设或修正结论属于知识性变更，按 `SKILL.md` 的 c 项处理。不在授权范围内的历史问题只报告。

## 4. 科研图表

- 每幅图围绕明确问题；图中对象、方向、步骤和关系在正文或图注中有解释。箭头说明数据流、依赖或时间关系，避免一根箭头混用语义。
- 自绘图沿用正文记号及排版；孤立阅读时，图或图注应能说明关键符号。科学性来自表达准确，不要求图中堆满公式。
- 实验图保留横纵轴、单位、刻度、图例、基线和子图标记；原论文若缺项，不自造，必要时在图注说明。没有数据不伪造曲线。
- 自绘图使用克制配色、清晰层次和可读字号；颜色不能是唯一编码，需配文字 / 线型 / 形状。正常嵌入尺寸下无裁切、重叠、模糊和缺字。
- 论文原图旁标论文来源、原图号和 PDF 页码，说明它支持哪一段内容；自绘重述标为「据……整理绘制」，二者不能混淆。图片资产放目标笔记同级 `images/`。
- 出图条件、文件格式和渲染检查见 `diagram.md`；论文原图提取见 `paper.md`。

## 5. 笔记结构与阅读成本

1. 新建长笔记通常采用「纲领 → 机制 / 方法 → 结果与边界」；可用 `0, 1, 2...` 编号。只有全局关系值得可视化时才设总链路。小条目、局部补充和纯目录移动不强加章节。
2. 同级章节保持同层级；解释某个公式不与整个算法流程并列。前置常识可放附录，但当前公式的必要符号定义不能推迟到文末。
3. 新写笔记默认不加「常见误解 / 易错点」；就近融入相关论述。用户明确要求或沿用既有小节时才单列。
4. 保留完整的仓库相对路径及必要版本信息，例如 `vllm/vllm/entrypoints/openai/protocol.py:170`；不要只给无法定位的文件尾名。路径不是必须暴露本机用户名的绝对路径。
5. 保留必要的表格列、适用前提和上下文差异，不为简洁删掉独有信息；不罗列可轻易查到的常见文件或命令。
6. 保留原 frontmatter；相关概念用能解析的 `[[笔记名#小节]]` 连接，避免为增加双链数量引入无关内容。
7. 去导航、站内搜索跳转和跟踪参数，保留真正支撑知识的原始来源、论文、官方文档及源码链接。
8. 中文表达，术语准确，新增密度对齐相邻小节；一句话足够就不写一段。必要示例可以保留，不能反复换写同一个结论。

规范的优先顺序是：用户要求与范围、事实和知识完整性、科研表达，再在这些前提下减少阅读成本。不得以篇幅短为由省略条件、符号定义或论文原图。
