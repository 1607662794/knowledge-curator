# 个人知识库整理（knowledge-curator）

把可复用知识吸纳进 Obsidian 知识库，默认 vault 根目录为 `C:\Users\Administrator\OneDrive\蔡文政的笔记`。全程中文；以低阅读成本完整承载理解所需的信息。

## 统一规范与优先级

用户本轮明确要求与授权优先，其次执行本 skill。`SKILL.md` 管范围与路由；[style.md](references/style.md) 是所有模式的科研风格定义；模式 reference 管具体步骤；[testing.md](references/testing.md) 将这些规范转为验收项。`vendor/` 只提供语法参考，不覆盖本 skill 的约束。历史笔记、记忆与工具探测记录是参考，不能覆盖当前明确要求或冒充当前环境事实。

**知识提取、笔记重构、独立绘图均先读 style.md，完成后按 testing.md 验收。** 论文知识提取笔记至少嵌入一张该论文原图；仅核验全文确实无图时可例外，具体见 [paper.md](references/paper.md)。

## 核心原则

- **指令逐条落实**：用户点名笔记就写那份；未点名时在授权主题内寻找合适载体，必要时新建并说明位置。没有合适载体且不能合理确定归属时，说明待处理项。
- **范围明确**：不因相关性擅自扩展主题或修改其他笔记。图片、绘图源码和来源记录属于目标笔记的配套产物；重构导致的入链修复按重构方案执行。
- **内容凝练但不丢信息**：去重到知识点，保留理解所需的假设、适用边界、代码路径和实验条件。不为凑结构追加案例、教程或小标题。
- **忠于来源**：区分来源事实、作者主张与整理者推导；未经证实的内容标明不确定性，不把解释冒充原文洞见。
- **通用化有边界**：对话中的一次性过程可抽象为通用机制；论文结果与代码行为仍须保留成立条件，不能抽象成无条件结论。

## 三种工作模式

| 模式 | 输入或场景 | 执行参考 |
| --- | --- | --- |
| 知识融入 A/B | 当前对话 / 本地聊天记录 | [chat-and-conversation.md](references/chat-and-conversation.md) |
| 知识融入 C | 论文 / PDF | [paper.md](references/paper.md) |
| 知识融入 D | 代码仓库 | [codebase.md](references/codebase.md) |
| 笔记重构 E | 调整结构、合并、拆分、移动、重命名 | [restructure.md](references/restructure.md) |

按请求判断模式，不为清晰的请求反复确认；只有影响内容、目标位置或操作范围的实质歧义才询问。重构保留全部独有知识和证据，具体授权边界见对应 reference。

## 主链路

1. **拆解指令**：列出每项要求、源材料、目标位置及验收条件；先确认源材料确有相关内容。
2. **定位与去重**：读取目标及必要上下文，按知识点判断重复，已覆盖则只补差异。未授权的全库风格改造不在范围内。
3. **提取或重组**：读取对应 reference，先形成全局认识再组织；小知识点就近插入，结构复杂时才增加总览或图。
4. **核实与科研表达**：按下述约束处理事实和歧义，按 style.md 定义符号、条件和图文关系。
5. **写入与配套产物**：写入授权位置，图放目标笔记同级 `images/`；论文原图与自绘图分别处理。
6. **验收**：按 testing.md 做通用检查与适用专项；记录通过、未通过或不适用及必要证据，不把未检查的项报成通过。
7. **反馈沉淀**：仅对明确、可复用的用户反馈，按 [taste-memory.md](references/taste-memory.md) 更新当前 agent 可用的记忆位置。

## 行为约束

- **a. 核实疑点**：先查源材料和本地证据；需要外部事实再检索权威来源。无法核实就标记边界，不猜测。
- **b. 澄清歧义**：仅当歧义影响知识含义、目标位置或授权范围且不能从上下文判断时询问；其余低风险选择直接执行。
- **c. 既有知识性错误**：发现目标笔记存在知识性错误，说明依据后征求确认；用户本轮已要求核对并修正该类错误时直接修正，不重复索要授权。纯排版修复可在本轮范围内直接做。
- **d. 外部来源纠错**：其他 AI / 网帖不是事实保证。对尚未融入的新内容先核实，再写入正确表述并说明实质偏差；如果同时需要改既有笔记的含义，按 c 处理。
- **e. 重构授权**：就地小幅融入直接做。架构级或大范围重构先提供迁移方案；用户已批准具体方案或明确授权自行决定时可执行，不重复确认。执行前确认可恢复状态，不假设 vault 一定已提交备份。
- **f. 不过度打扰**：遵守已有授权，常规整理、绘图、验证直接执行。软件安装与外部服务调用仍遵守当前运行环境权限。

## 反模式

- 以相邻主题顶替源材料中没有的用户指定主题。
- 为小幅补充强制添加「0. 一句话结论」「1. 总链路」和完整论文模板。
- 新写笔记默认追加「常见误解 / 易错点」，把可就近解释的内容拆散。
- 将实验观察写成无条件保证，或为了显得确定而隐去来源的不确定性。
- 用 ASCII 多分支图替代科研图，或用自绘图、OCR 文本替代要求保留的论文原图。
- 修改未授权笔记、静默丢弃独有信息、将同一结论反复改写凑篇幅。
